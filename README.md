# self-learning-javaweb
JavaWeb自学成长仓库 | SpringBoot、Web后端基础练习案例

## 📌 仓库说明
本仓库记录JavaWeb后端基础自学全过程，包含SpringBoot入门、请求响应、静态资源、前后端交互案例。
前置学习仓库：self-learning-java（Java SE基础）。

## 📁 目录结构
- `maven_project`: 原生Java Web基础练习
- `springboot-web-01`: SpringBoot基础接口开发、前后端交互
- `springboot_web_quickstart`: SpringBoot快速入门基础案例
- `mysql_sql_project`: MySQL建表、数据库练习模块，DDL、DML、DQL练习SQL脚本

## ⚙ 环境与工具
- JDK：Java 8+
- 构建工具：Maven
- IDE：IntelliJ IDEA
- 版本控制：Git + GitHub

## 🚀 如何运行
1. 本地配置JDK与Maven环境
2. IDEA导入项目，等待依赖下载完成
3. 运行SpringBoot启动类，访问对应接口地址
